# Provenance and dependency boundary
This package consolidates the user's accumulated editing preferences, local implementation experience and paraphrased reference analysis. Original source videos, reference frames, raw transcripts, models and third-party libraries are not bundled.

Related upstream projects:
- Hyperframes renderer and official domain guidance: https://github.com/heygen-com/hyperframes
- Student-kit workflow inspiration: https://github.com/nateherkai/hyperframes-student-kit
- Motion pack catalog: https://github.com/iart-ai/motion-skills
- Animation/art direction guides: https://github.com/iart-ai/motion-design-skills
- Mask/type guides: https://github.com/iart-ai/kinetic-typography-skills
- Remotion craft patterns: https://github.com/haidrrrry/claude-remotion-skill

The package does not redistribute these repositories or their skill folders. Dependencies are installed separately and remain subject to their own licenses. GSAP helper functions are authored for this package from the locally developed workflow. No claim that installing this package installs all upstream tools or changes a model's weights.
